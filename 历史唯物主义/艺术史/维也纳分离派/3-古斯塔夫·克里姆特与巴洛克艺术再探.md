# 古斯塔夫·克里姆特与巴洛克艺术再探

*(原文法语：网址：https://materialisme-dialectique.com/gustav-klimt-et-le-baroque-detourne/)*

当我们对古斯塔夫·克里姆特感兴趣时，我们必须明白，就像对阿尔丰斯·穆夏一样，我们面对的不是画家，而是装饰家。

![img](https://materialisme-dialectique.com/images/dossiers/secession-viennoise/klimt.jpg)*古斯塔夫·克里姆特*（1862-1918）

俄罗斯的巡回画派来自一个与极其软弱的资产阶级联系紧密的受过教育的小阶层，这使他们完全接受了民主的理念，转向了人民的现实。

奥地利的情况则不同，那里的资产阶级势力强大得多，因此形成了真正的客户群体。

这使得它有可能呈现出非常明显的印象派、象征主义和颓废主义倾向。

然而，由于资产阶级在反对封建主义的民族斗争中具有进步的一面，分离派也具有进步的一面，该运动的艺术家们将其理解为呼吁在日常生活中进行艺术创作，呼吁民族艺术。

因此，古斯塔夫·克里姆特是奥地利民族资产阶级画家，而阿尔丰斯·穆夏是捷克民族资产阶级画家。

![img](https://materialisme-dialectique.com/images/dossiers/secession-viennoise/klimt-adele.jpg)*阿黛尔·布洛赫-鲍尔的肖像*(1907)

由于巴洛克艺术在奥地利作为反宗教改革意识形态[^1]的重要性，艺术家们不得不违背自己的意愿，追随这一历史潮流。

奥地利民族艺术的表达方式绕开了巴洛克风格，而捷克民族艺术则不然。捷克民族艺术，如阿尔丰斯·穆夏的作品，借鉴了斯拉夫历史文化，以反驳奥地利的民族压迫，而巴洛克风格正是这种压迫的意识形态和文化载体。

众所周知，巴洛克艺术追求**整体统一性**：它的外观刻意营造动感，充盈整个空间，目的是压倒人的理性；它传递这样一种观念 —— 世间万物不可被人理解，唯有上帝凭借其独一的恒定性，可以洞悉一切[^2]。

在后续作品中，古斯塔夫・克里姆特极为出色地将**形象再现**与配套的装饰融为一体，营造出极具典型性的氛围。

 我们在这里看到一种典型装饰，它专为烘托情境、渲染氛围而生。 

为充分理解装饰这一议题，我们来看看《贝多芬横饰带》，这件作品描绘了种种敌对力量。

![img](https://materialisme-dialectique.com/images/dossiers/secession-viennoise/klimt-frise.png)

从我们可以看出，古斯塔夫·克里姆特深受象征主义和颓废主义的影响，而且这种情况只会越来越严重。

我们必须超越这种神秘主义的转变，才能发现古斯塔夫·克里姆特作品中典型的装饰性趣味。

以下作品实现了非常有趣的装饰性综合，体现了对某个理念或人物的整体性表达。

我们看到的不仅仅是一幅简单的画作；我们置身于一个装饰之中。

这里有*《爱》，*描绘的是钢琴家兼钢琴教师约瑟夫·彭鲍尔，以及演员约瑟夫·莱温斯基饰演的卡洛斯。

![img](https://materialisme-dialectique.com/images/dossiers/secession-viennoise/klimt-liebe.jpg)古斯塔夫·克里姆特，*《爱》*（1985）

![img](https://materialisme-dialectique.com/images/dossiers/secession-viennoise/klimt-pembaur.jpg)古斯塔夫·克里姆特，*《钢琴家兼钢琴教师约瑟夫·彭鲍尔肖像》*（1890年）

![img](https://materialisme-dialectique.com/images/dossiers/secession-viennoise/klimt-lewinsky.jpg)古斯塔夫·克里姆特，*演员约瑟夫·莱温斯基饰演卡洛斯*（1895 年）

正是从这个意义上讲，我们必须理解古斯塔夫·克里姆特为何能够成功创作出杰出的作品。

如果他只是一位奥地利风格的印象派画家，他就不会被发现。

**只有将自己与当时奥地利文化的进步维度联系起来，他才能在典型的装饰意义上进行艺术上的综合。**

完美展现这一高潮的画作当然是*《吻》。*

![img](https://materialisme-dialectique.com/images/dossiers/secession-viennoise/klimt-baiser.jpg)古斯塔夫·克里姆特，*《吻》*（1908-1909）

在教权占据主导的时代背景下，古斯塔夫・克里姆特同样着重凸显肉身维度。

 同一时期，奥地利社会民主党大力推广游泳、体操与自行车运动。

 这是一场对身体的重新夺回：肉身曾被激进的天主教所异化。这套天主教体系源自反宗教改革，目标是重新争取那些历史上改投新教的民众。

 理解奥地利文化的文化关键在于：这个国家不单单是天主教国家，而是**再天主教化**[^3]的国家。 

因此，情欲主题在克里姆特作品里表现得十分强烈；他常常透过象征主义、颓废主义的视角，将女性视作一种绝对存在，同时女性又成为带有性崇拜意味的对象。

这里是*达娜厄、女人的三个阶段、处女们、朱迪斯和霍洛弗尼斯。*

![img](https://materialisme-dialectique.com/images/dossiers/secession-viennoise/klimt-danae.jpg)古斯塔夫·克里姆特，*《达娜厄》* （1907年）

![img](https://materialisme-dialectique.com/images/dossiers/secession-viennoise/klimt-3ages.jpg)古斯塔夫·克里姆特，《*女人的三个阶段*》（1905年）

![img](https://materialisme-dialectique.com/images/dossiers/secession-viennoise/klimt-vierges.jpg)古斯塔夫·克里姆特，*《处女们》*（1913）

![img](https://materialisme-dialectique.com/images/dossiers/secession-viennoise/klimt-judith.jpg)古斯塔夫·克里姆特，*朱迪思和霍洛弗尼*(1901)

不难看出，古斯塔夫·克里姆特在艺术上正朝着这种典型的装饰风格发展，这种组合营造出一种氛围，试图通过印象派来保持现实主义。

这本身就是一个**矛盾**，但他有时能够有效地克服这个矛盾。

这一点在以下作品中体现得非常明显：*《钢琴前的舒伯特》和《索尼娅·克尼普斯肖像》。*

![img](https://materialisme-dialectique.com/images/dossiers/secession-viennoise/klimt-schubert.jpg)古斯塔夫·克里姆特，*《舒伯特在钢琴旁》*（1899年）

![img](https://materialisme-dialectique.com/images/dossiers/secession-viennoise/klimt-sonja.jpg)古斯塔夫·克里姆特 (Gustav Klimt)，*索尼娅·克尼普斯 (Sonja Knips) 的肖像*(1898)

维也纳这座城市以及奥地利天主教的特点是与死亡有着非常特殊的关系，死亡是一个文化上无处不在的主题，甚至被认为是维也纳特有的事物！

虚构的17世纪歌手马克思·奥古斯丁也因醉酒后与所有瘟疫受害者一起被集中起来，醒来时发现自己身处停尸房而闻名……

这一主题在民族作家古斯塔夫·克里姆特的作品中得到了很大程度的体现；将此与象征主义-颓废主义以及他对病态的迷恋联系起来是错误的。

这里是*生命与死亡，希望一，希望二。*

![img](https://materialisme-dialectique.com/images/dossiers/secession-viennoise/klimt-vie-mort.jpg)古斯塔夫·克里姆特，*《生与死》*（1910-1915）

![img](https://materialisme-dialectique.com/images/dossiers/secession-viennoise/klimt-espoir.jpg)古斯塔夫·克里姆特，*《希望》*（1903年）

![img](https://materialisme-dialectique.com/images/dossiers/secession-viennoise/klimt-espoir2.jpg)古斯塔夫·克里姆特《*希望二世》*（1907-1908）

古斯塔夫·克里姆特经常以系列作品的形式创作，作为装饰的一部分，例如在大学里。

这是位于医科大学内的*许癸厄亚女神像，象征着健康。其典型的装饰风格至今仍保留着。*

![img](https://materialisme-dialectique.com/images/dossiers/secession-viennoise/klimt-Hygieia.jpg)古斯塔夫·克里姆特， 《许*癸厄亚》，* 20世纪早期

最后，这里有两幅极具奥地利民族文化代表性的作品：《山毛榉林一号》（Buchenwald I，即一片山毛榉树林）与《完成》（L’accomplissement）。 

在这两幅作品当中，我们能够看到在这一文化框架下图像创作的两大核心驱动力：**用于沉思冥想的装饰性，置于氛围感场景之中；同时艺术家试图把这份体验推向极致的复杂层次。**

![img](https://materialisme-dialectique.com/images/dossiers/secession-viennoise/klimt-buchenwald.jpg)古斯塔夫·克里姆特，《布痕*瓦尔德集中营 I》*（1902 年）

![img](https://materialisme-dialectique.com/images/dossiers/secession-viennoise/klimt-accomplissement.jpg)古斯塔夫·克里姆特，*《实现》*（1905-1909）

它是巴洛克风格及其多方面的丰富性，被重新用于典型的装饰风格。



[^1]: 16 世纪宗教改革兴起，新教在欧洲扩散，天主教会发起**反宗教改革**，不再单纯依靠说教，而是用震撼、华丽、富有感染力的艺术打动信众，重新巩固信仰。 **巴洛克就是反宗教改革最核心的视觉宣传工具**。它在意大利发源，传入奥地利（哈布斯堡王朝领地）后被大力扶持；哈布斯堡皇室、教会大量修建教堂、宫殿，用动态光影、强烈戏剧感、宏大华丽的巴洛克艺术，彰显**天主教权威 + 王朝统治的神圣性**。
[^2]: 文艺复兴相信人类理性可以理解世界；巴洛克用强烈光影、戏剧化场面冲击人的感官，让观者产生惊叹、震撼、狂喜的宗教情绪。 **哲学 / 神学含义**：人的理性不足以理解这个变幻不定的尘世；唯有上帝是唯一不变、稳定的存在。这正是**反宗教改革**的意识形态目标。
[^3]: 在宗教改革时期，奥地利及哈布斯堡领地内不少民众曾转向新教。于是哈布斯堡政权联合天主教会，依托反宗教改革运动，动用巴洛克艺术、教育、行政力量，**强行把这片土地重新拉回天主教信仰**，也就是**再天主教化**。 这种天主教不是自然形成的民间信仰，是**经过斗争、刻意重建的、高度强势的教权秩序**。 这套宗教文化的特点：严格规训肉体，贬抑感官、情欲，认为肉体欲望是原罪，需要克制。
